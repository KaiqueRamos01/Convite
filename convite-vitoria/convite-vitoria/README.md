# Convite para a Vitória

Site estático (HTML + CSS + JS, sem build). Todas as fotos ficam na pasta `img/`.

## Como publicar no GitHub Pages

1. Crie um repositório novo no GitHub (pode ser privado ou público, ex.: `convite-vitoria`).
2. Envie o conteúdo desta pasta para a raiz do repositório (`index.html`, `img/`, `.nojekyll`).
3. No repositório, vá em **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e salve.
5. Em 1 a 2 minutos o site aparece em `https://SEU-USUARIO.github.io/convite-vitoria/`.

Obs.: GitHub Pages em repositório privado exige plano pago. Se o repositório for público, qualquer pessoa com o link consegue abrir o site.

## Onde editar

- Legendas das fotos: lista `photos` no final do `index.html`.
- Número do WhatsApp e mensagem de resposta: link `id="wa"` no `index.html` (formato `wa.me/55DDDNUMERO?text=...`).
- Horário, data e local: telas 4 e 5 do `index.html`.
